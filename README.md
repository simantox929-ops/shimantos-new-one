# SIMANTO SHANAL — 3D Portfolio V4

A GitHub Pages-ready personal portfolio with a red, black, and white 3D animation theme. Visible website copy is English (US).

## Edit your content
- Open `index.html` to change your name, About text, skills, projects, and certificate titles.
- Replace social placeholder URLs near the `#contact` section with your own GitHub, LinkedIn, Facebook, Instagram, and email links.
- Put your CV at `assets/cv.pdf`.
- Put certificates at `assets/certificate-1.pdf`, `assets/certificate-2.pdf`, etc.
- For real gallery photos, replace each `.photoVisual` block in `index.html` with an `<img>` and add styling as desired.

## Like and comments
This static GitHub Pages version saves likes/comments in the visitor's own browser with localStorage. Shared public likes/comments require a backend such as Firebase or Supabase.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload the files *inside* this folder to your repository root. `index.html` must be at the root.
3. Commit the files.
4. Go to Settings > Pages.
5. Choose Deploy from a branch, `main`, `/ (root)`, then Save.

## Main animation features
3D loading cube, rotating hero cube, orbital rings, pointer parallax, 3D card tilt, animated skills orbit, flipping certificates, animated gallery geometry, particle field, scroll reveal, and animated contact orbit.
