# SIMANTO SHANAL — Personal Website

Ready for GitHub Pages. No build tools required.

## Edit these first
- `index.html`: name, bio, skills, projects, certificate titles and contact URLs.
- Social placeholders: search for `YOUR_USERNAME`, `YOUR_ID`, `YOUR_NUMBER`, and `your@email.com`.
- `assets/cv.pdf`: put your CV here.
- `assets/certificate-1.pdf`, `certificate-2.pdf`: put certificate PDFs here.
- `assets/photo-1.jpg`, `photo-2.jpg`, `photo-3.jpg`: add gallery photos using these filenames.

## Included features
- Responsive premium portfolio layout
- Dark/light mode with saved preference
- CV view + download buttons
- Certificate section
- Contact/social icons that open your profiles
- Photo gallery with like + comment interface
- Likes/comments saved with `localStorage`
- Projects, skills, about, animations, SEO metadata and custom 404

## Important: likes/comments
This version is 100% static and works on GitHub Pages. Likes/comments are saved only in each visitor's browser. To make likes/comments public and shared between all visitors, add a backend/database such as Firebase or Supabase.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (not the outer ZIP).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose your main branch and `/ (root)`, then Save.

## Dark mode
The sun/moon button in the navigation toggles the theme. The choice is saved automatically in the browser.
